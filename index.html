PRÁCTICA 4. ¿QUÉ ES HTML5?

HTML5 es la quinta y más reciente gran versión de HTML, el lenguaje de marcado estándar utilizado para estructurar y presentar todo el contenido en la World Wide Web. Funciona como el "plano arquitectónico" o el esqueleto de un sitio web, indicándole al navegador cómo debe organizar elementos como textos, imágenes, formularios y contenido multimedia.

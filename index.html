PRÁCTICA 4. ¿QUÉ ES HTML5?

HTML5 es la quinta y más reciente gran versión de HTML, el lenguaje de marcado estándar utilizado para estructurar y presentar todo el contenido en la World Wide Web. Funciona como el "plano arquitectónico" o el esqueleto de un sitio web, indicándole al navegador cómo debe organizar elementos como textos, imágenes, formularios y contenido multimedia.

Introduce nuevas etiquetas semánticas, como <header>, <footer>, <article> y <section>, que permiten a los desarrolladores web estructurar mejor el contenido y mejorar la accesibilidad. Además, HTML5 incluye soporte nativo para audio, video, gráficos 2D y 3D, almacenamiento local y muchas otras características avanzadas que facilitan la creación de aplicaciones web interactivas y dinámicas.

FORMULARIOS

Los formularios en HTML5 sufrieron una auténtica revolución. Antes, validar si un usuario escribía bien su correo o poner un calendario requería mucho código de JavaScript. Con HTML5, el propio navegador se encarga de casi todo de forma nativa a través de nuevos tipos de entrada (type) y atributos de validación.

¿QUÉ VENTAJAS OFRECE HTML5?

  • Mayor compatibilidad con dispositivos móviles.
  • Mejor soporte para multimedia (audio y video).
  • Mejoras en la semántica y estructura del contenido.
  • Soporte para gráficos y animaciones mediante Canvas y SVG.
  • Almacenamiento local y offline.
  • Mejoras en la accesibilidad web.
